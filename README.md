# Brenda Ranieri — Artist Website

Static bilingual artist website for Brenda Ranieri.

## Status

The repository is in its foundation and design-definition phase. Content will be supplied directly by the artist; no WordPress migration is planned.

## Product direction

- Next.js with the App Router and TypeScript
- Static Spanish and English routes
- Repository-managed MDX content
- No database or CMS
- Vercel deployment
- Editorial archive structure with atmospheric project storytelling

## Proposed sections

- Exhibitions & Projects
- Bio
- Selected Artworks
- Studio

The detailed information architecture and bilingual routing proposal are documented in [`docs/information-architecture.md`](docs/information-architecture.md).
